## GPU-free panel tooling

`prepare_pixel_robustness.py` writes four fixed models per condition, isolated
full INIs, paired seeds, rotated family order, budgets/cadence, source snapshots/
hashes, native build/train command arrays and evaluation gates. No GPU/model
executes. It supplies **build-only**, deliberately no full campaign launcher
while exact adapters and inference gates remain unfinished. Python is external
configuration/provenance glue; optimizer/training/inference stay native C/CUDA.

```bash
# First plumbing panel: 6 tasks x 4 models = 24 jobs, prepared only.
.venv/bin/python research/prepare_pixel_robustness.py \
  --out build/pixel-robustness/FRESH_DEFAULT_ID

# Full drawing inventory: 38 conditions x 4 models = 152 short plumbing jobs.
.venv/bin/python research/prepare_pixel_robustness.py \
  --appearances all --out build/pixel-robustness/FRESH_APPEARANCE_ID

# Compile only; no neural/GPU execution. Select this machine's actual target.
NVCC_ARCH=sm_120 bash build/pixel-robustness/FRESH_DEFAULT_ID/build-only.sh
```

## More useful drawing axes

Future versioned presets: foreground/background palettes, integer translations,
piece outlines, controlled borders/background texture, disk-versus-square
balls/birds, and brick/pipe gaps. Require literal pixel fixtures, unchanged
physics and no game RNG consumption. Classify reversible transforms, lossy
raster changes and input-size changes separately. Reflection leaves action IDs
fixed; it tests learning/transfer, not an automatically equivalent trained policy.
Smaller occupied boards do not reduce fixed-shape FLOPs. Large strides may
miss tiny pieces; retain those outcomes. RGB/larger images require a separate
shared-kernel extension validating all encoders.
