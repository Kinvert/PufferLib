# Sprite overnight supervisor: local integration evidence

October16, RTX5060/G240. No overnight/5090 run was started. This report
qualifies short integration and scoped encoder numerics, not learning quality,
Pareto superiority, held-out generalization or independent full-learner math.

The new supervisor trains one proposed architecture across all six sprite
games, evaluates all three skins, aggregates complete final results, and
passes score plus once-per-job training cost into native PROTEIN. Movement
and gaze are learned independently. Python supervises/audits; native C/CUDA
implements architectures, training, inference and the optimizer.
